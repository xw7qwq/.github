# xw7

[Panel](https://lucius7.dev/) · [Blog](https://blog.lucius7.cn/) · [Practice](https://lucius7.dev/oj/) · [Now](https://lucius7.dev/now/)

Lucius7's personal projects: writing, competitive programming, device status, and self-hosted health and ledger tools.

| Repository | Purpose | Website |
| --- | --- | --- |
| [panel](https://github.com/xw7qwq/panel) | Astro / Svelte panel, read-only API, and MCP | [lucius7.dev](https://lucius7.dev/) |
| [ui](https://github.com/xw7qwq/ui) | Shared colors, typography, navigation, and chart components | [Component guide](https://github.com/xw7qwq/ui#readme) |
| [blog](https://github.com/xw7qwq/blog) | Articles and notes, built on Fuwari | [Blog](https://blog.lucius7.cn/) |

| [health](https://github.com/xw7qwq/health) | Health collection and outbound panel snapshots | [Public summary](https://lucius7.dev/health/) |
| [ledger](https://github.com/xw7qwq/ledger) | Fava deployment, snapshot jobs, and private ledger backups | [Fava](https://fava.lucius7.dev/) |

Servers push health and ledger snapshots to the panel; the panel never connects to the servers. Public health data is limited to seven-day averages of sleep and steps, ending yesterday. Detailed health, ledger data, and MCP tools require authorization. Real ledger files and backups stay private.

Repository names describe their purpose. Deployment hostnames and public data endpoints retain compatibility independently. See the [maintenance conventions](https://github.com/xw7qwq/.github/blob/main/docs/maintenance.md) for naming, shared UI, CI, and license boundaries.
