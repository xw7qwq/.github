# xw7qwq 的组织配置

这个仓库维护 [组织主页](profile/README.md)、共享贡献规范和默认 Issue / Pull request 模板。各项目自己的约定优先；没有自定义模板的仓库使用这里的默认模板。

- [贡献规范](CONTRIBUTING.md)：分支、提交、审查、验证与合并。
- [仓库维护约定](docs/maintenance.md)：保护规则、必需检查和长期分支。
- [组织主页](https://github.com/xw7qwq)：项目入口。

修改本仓库后运行 `python3 scripts/check_repository.py`。CI 会校验本地 Markdown 链接和 SVG 格式。
